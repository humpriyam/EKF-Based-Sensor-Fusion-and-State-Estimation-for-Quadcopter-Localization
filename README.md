# EKF-Based Sensor Fusion and State Estimation for Quadcopter Localization

This repository contains the MATLAB and Simulink models for Basic Kinematics, Propeller Modelling, and comparision between different formulas used to calculate torque and thrust of a propeller; More coming.....
## Repository Structure

The current repository reflects the foundational kinematics and propulsion mechanics, with designated directories for the upcoming advanced dynamic modeling and filtering algorithms:

### 📁 /Kinematics
*   `rot2d.m`: MATLAB script for visualizing 2D planar coordinate transformations and vector rotations[cite: 3].
*   `rot3d.m`: MATLAB script for computing and visualizing 3D rigid body rotations using Euler angles to map the Body-Fixed Frame to the Inertial Frame[cite: 3].

### 📁 /Propulsion_Modeling
*   `th_to_r.m`: Evaluates and plots thrust and torque distribution along the radial length of a single propeller blade[cite: 3].
*   `th_to_rpm.m`: Calculates total quadcopter thrust and torque across varying motor RPMs using strict integral Blade Element Theory (BET)[cite: 3].
*   `th2_to2_rpm.m`: Computes thrust and torque versus RPM using a Simplified Lumped-Parameter Model, which collapses the complex integrals into dimensionless thrust ($C_T$) and torque ($C_Q$) coefficients[cite: 3].

### 📁 /Simulink_Models
*   `final.slx`: A Simulink environment designed to cross-verify the analytical BET calculations and Lumped-Parameter models directly against the built-in Simulink Multirotor dynamics physics block[cite: 3].

## Future Work Roadmap

The upcoming phases of the project will focus heavily on sensor integration and control systems:
1.  **Non-Linear 6-DOF Equations:** Replacing small-angle approximations with strict Newton-Euler formulations for translational and rotational motion.
2.  **Gyroscopic Torque Integration:** Mathematically modeling the gyroscopic effect generated by the high-speed rotation of the propeller masses during pitch and roll maneuvers.
3.  **IMU Sensor Modeling:** Simulating the thermo-mechanical white noise and wandering bias inherent to Micro-Electro-Mechanical Systems (MEMS) gyroscopes and accelerometers[cite: 3].
4.  **EKF Implementation:** Fusing the simulated IMU sensor data using an Extended Kalman Filter to mathematically correct sensor drift and accurately estimate the drone's true attitude over time[cite: 3].
